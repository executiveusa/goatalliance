# PNW AI Directory Upgrade Package

This package upgrades the GOAT/Phlash direction into an AI-readable local contractor directory for the Pacific Northwest.

## Added vertical

Pressure washers are now included with an EcoWash social-purpose lane.

## Added app features

- Home page repositioned around AI-readable contractor proof.
- Directory index.
- Dynamic vertical pages for plumbers, HVAC, roofers, painters, and pressure washers.
- 30 backdated blog posts from 2026-06-08 through 2026-07-07.
- Blog index and post pages.
- SVG image system.
- llms.txt and llms-full.txt.
- sitemap route.
- JSON-LD schema helpers.
- Hermes cron plan.
- Paperclip company config.
- Black Swan strategy doc.
- Grants, loans, and secret-angle doc.
- Site copy system.

## Install/run

```bash
npm install
npm run dev
npm run build
```

## Caution

Demo contractor profiles are intentionally labeled `demo-seed`. Do not publish them as verified businesses. Real profiles require proof checks.
